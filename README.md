# Скупщики MOTR

Статический инструмент для сопоставления склада персонажа с активными заявками скупщиков MOTR.

## Локальная работа

Откройте `index.html` в браузере и загрузите сохранённую страницу личного раздела и одну или несколько страниц вендинга в режиме скупки.

## GitHub Pages

После первого пуша в ветку `main` откройте в настройках репозитория **Settings → Pages** и в разделе **Build and deployment** выберите **GitHub Actions**. Рабочий процесс `.github/workflows/deploy-pages.yml` опубликует сайт автоматически.
